# Ralph Progress Log

## Codebase Patterns
- All pipeline code is in video-production/library/ (organized by domain: voiceover, music, sfx, mixing, scoring, rendering, pipeline, remotion)
- Python files have origin comments: `# Origin: {version} — extracted to library on 2026-03-23`
- Remotion components have JSDoc headers with @component, @origin, @description tags
- Requirements go in library/pipeline/requirements.txt
- New directories may need to be created (e.g., library/distribution/)
- The pipeline uses async Python with asyncio, tenacity for retries
- Audio processing uses pydub and numpy/scipy currently
- Scoring uses Google Vertex AI / Gemini 2.5 Pro
- All files are code-only (no binary assets tracked in git)
- EncodingPreset.ffmpeg_video_args() in pipeline_config.py is the central point for all FFmpeg encoding flags — modify there for global encoding changes
- assembler.py has some hardcoded ffmpeg commands (e.g., color grading) that bypass EncodingPreset — check both files when changing encoding
