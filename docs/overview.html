Commands

Key entry points for the production pipeline.

$ python genetic_optimizer.py --optimizer optuna --rounds 15
Bayesian optimization of voiceover parameters — tests 15 rounds of TTS settings to find the best voice delivery.
$ python gemini_video_scorer.py score --tier dev --video render.mp4
Score a rendered video against the 7-dimension rubric using Gemini 2.5 with context caching.
$ python vmaf_gating.py current.mp4 previous.mp4
Deterministic regression check — compare VMAF/SSIM between current and previous render to catch quality drops.
$ python kling_generator.py "Developer coding" --duration 5
Generate a 5-second B-roll clip from a text prompt using Kling 3.0 video generation.
$ python temporal_workflow.py worker
Start a Temporal worker for crash-safe durable pipeline execution with automatic retries.
$ python late_publisher.py video.mp4 --platforms youtube linkedin
Distribute the final video to YouTube and LinkedIn via the Late API — supports 13 platforms total.

Architecture

Planner / Generator / Evaluator

▼
Planner
Claude acts as the planning layer — decomposing high-level goals into pipeline phases, shot lists, and scene composition decisions.
Generator
Temporal and Dagster orchestrate the generation phase — executing TTS, video generation, music synthesis, and rendering as durable workflows.
Evaluator
Gemini 2.5 (7-dim rubric), VMAF/SSIM (regression gating), and VBench (temporal quality) form a three-layer evaluation system that gates every output.

Scoring System

▼
7-Dimension Video Rubric (Gemini)
Visual quality, pacing, narrative coherence, audio-visual sync, text readability, transitions, and overall polish — scored by Gemini 2.5 Flash/Pro with context caching for consistency.
9-Criterion Acoustic Rubric (librosa + UTMOSv2)
PESQ, STOI, spectral centroid, pitch stability, jitter, shimmer, SNR, LUFS compliance, and UTMOSv2 mean opinion score — fully deterministic audio quality assessment.
11-Criterion Script Rubric
Hook strength, narrative arc, emotional beats, pacing, CTA placement, technical accuracy, audience targeting, jargon balance, transition quality, visual cue scripting, and deliverable length.

Audio Pipeline

▼
1. Silero VAD
Voice activity detection identifies speech segments to protect during ducking.
2. Frequency-Aware Ducking
Music attenuated specifically in the 200–4000 Hz speech band, preserving bass and shimmer.
3. Pedalboard Compression
Spotify Pedalboard applies dynamic range compression for broadcast-ready consistency.
4. LUFS Normalization
Final loudness normalized to -14 LUFS (YouTube) or -16 LUFS (podcast) for platform compliance.

Encoding Presets

▼
H.264 -tune animation — Optimized for screen recordings and motion graphics with clean edges
AV1 (SVT-AV1) — 50% smaller file size at equivalent quality, ideal for web distribution
VideoToolbox (macOS) — Hardware-accelerated encoding, 4x faster than software H.264
YouTube 1080p/4K — Platform-optimized bitrate ladders with 2-pass VBR
TikTok 9:16 — Vertical format with safe-zone padding for UI overlays
LinkedIn 1:1 — Square crop with title-safe margins for feed autoplay
Product Hunt — GIF-friendly loop with aggressive file-size optimization

Neurolink AI Layer

TypeScript agents powered by @juspay/neurolink — structured AI scoring, analysis, and creative direction.

Policy Creator
5 policies: video score (7 dims), script lock (9.0 threshold), acoustic quality, scene quality, agent execution bounds.
Policy Enforcer
Real-time rule checking during agent execution. Supports min/max/equals/contains/regex conditions on any output field.
Policy Validator
Post-execution compliance report. Aggregates violations, classifies by severity, determines release readiness.
