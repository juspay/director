## Consistency Tips

1. **Seed locking (Midjourney):** After generating the first successful pose, note the seed value (`--seed XXXXX`) and reuse it in subsequent prompts to maintain facial consistency.

2. **Character reference (Midjourney v6+):** Use the `--cref` flag with the original reference image URL:
   ```
   --cref [URL_of_tara-neurolink-square.png] --cw 100
   ```
   This tells Midjourney to match the character's face and design. `--cw 100` gives full weight to the character reference.

3. **DALL-E 3 consistency:** DALL-E 3 does not support seed or character references. For best results:
   - Always include the full character description in every prompt (do not abbreviate)
   - Generate 3-4 variations per pose and select the most consistent one
   - If using the ChatGPT interface, keep prompts in the same conversation thread for better stylistic continuity

4. **Logo detail:** The neural network logo is the hardest element to keep consistent. If the logo renders poorly, add this phrase: "the logo is a simple blue circle containing 6-7 small dots connected by thin lines, with 2-3 dots colored orange instead of blue"

5. **Negative prompts (Midjourney):** Always include `--no glasses, hat, jewelry, freckles, realistic skin` to prevent drift from the Pixar style.

6. **Aspect ratios by use:**
   - `1:1` — Slack avatar, social thumbnails
   - `3:4` — Character card, vertical compositions
   - `16:9` — Video frame, wide compositions with space for text
