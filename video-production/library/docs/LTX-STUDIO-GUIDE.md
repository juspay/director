## Step-by-Step Process

### STEP 1: Sign Up

1. Go to **https://ltx.studio**
2. Click **"Start for free"**
3. Create account (Google sign-in is fastest)
4. You get **800 free credits** immediately

### STEP 2: Create New Project

1. Click **"New Project"** or **"Create"**
2. Select **"From Script"** (paste your screenplay)
3. Set project settings:
   - **Aspect Ratio:** 16:9 (landscape)
   - **Style:** Cinematic / Modern Tech
   - **Duration target:** ~3 minutes

### STEP 3: Paste the Script

Copy-paste the screenplay below into LTX Studio's script editor. It will auto-break into scenes and generate storyboard thumbnails.

## THE SCREENPLAY (copy this entire block)

STYLE: Cinematic tech documentary, dark modern aesthetic
MUSIC: Ambient electronic, building tension to resolution

### STEP 4: Set Up Character Consistency

After LTX generates the initial storyboard:

1. Go to **Elements** panel
2. Create a **Character Profile** for "Tara":
   - Type: AI/Software interface
   - Visual: Slack bot avatar with blue/teal colors
   - Keep consistent across scenes 4, 5A, 5B, 5C
3. Create **Style Element** for "Slack UI":
   - Dark mode Slack interface
   - Keep consistent across all Slack screenshot scenes

### STEP 6: Refine Each Scene

For each auto-generated scene:

1. **Review the thumbnail** — does it match the direction?
2. **Adjust camera** — use LTX camera controls:
   - Scene 1: Static → slow zoom in
   - Scene 2: Slow pan / dolly
   - Scene 3: Quick cuts (fast camera changes)
   - Scene 4: Static with subtle zoom
   - Scenes 5A-5C: Static (screen recording feel)
   - Scene 6: Dynamic zoom on each stat
   - Scene 7: Slow reveal/pan
   - Scene 8: Static, centered
3. **Use "Retake"** on any scene that doesn't look right (regenerate without losing others)

### STEP 7: Add Audio

1. **Voiceover option A — Use existing ElevenLabs audio:**
   - Upload your generated MP3 files from `assets/voiceover/`
   - Use LTX's Audio-to-Video feature to lip-sync if needed
   - Files: `act1_hook.mp3` through `act8_cta.mp3`

2. **Voiceover option B — Generate fresh in LTX:**
   - Use LTX's built-in voice generation
   - Paste the voiceover text for each scene
   - Select a professional male voice (warm, authoritative)

3. **Background music:**
   - Use LTX's Sound Design tools
   - Style: Ambient electronic, building tension
   - Or upload your existing `assets/music/background_music_looped.mp3`

### STEP 8: Timeline Editor

1. Open the **Timeline** view
2. Verify scene durations match the script:
   - Scene 1: ~14s
   - Scene 2: ~29s
   - Scene 3: ~11s
   - Scene 4: ~18s
   - Scene 5A: ~19s
   - Scene 5B: ~22s
   - Scene 5C: ~16s
   - Scene 6: ~25s
   - Scene 7: ~12s
   - Scene 8: ~6s
3. Trim/extend as needed
4. Ensure audio-video sync is tight
5. Add transitions between scenes (crossfade, 0.5s)

### STEP 9: Export

1. Click **Export** / **Render**
2. Settings:
   - Resolution: **1080p** (or 4K if available)
   - Format: **MP4**
   - Quality: **Highest available**
3. Download the final file

### STEP 10: Final Polish (optional, with ffmpeg)

If you want to add captions or embed a thumbnail:

```bash
# Add subtitles (if you have an SRT file)
ffmpeg -i tara_ltx_final.mp4 -vf "subtitles=captions.srt" -c:a copy tara_final_captioned.mp4

# Embed thumbnail for social platforms
node .claude/skills/elevenlabs-remotion-skill/generate.js \
  --embed-thumbnail tara_ltx_final.mp4 \
  --thumbnail thumbnail.png \
  --output tara_final.mp4
```

## Tips for Best Results

1. **Spend credits wisely** — Preview thumbnails before generating full scenes
2. **Use "Retake"** — Regenerate individual scenes without losing the whole project
3. **Upload screenshots** — Real Slack screenshots as reference images dramatically improve quality
4. **Scenes 5A-5C are critical** — These show real product. Use reference images heavily.
5. **Scene 6 (stats)** — Kinetic text works best with LTX's text animation tools
6. **Scene 8 (CTA)** — Keep it simple. Dark bg, white text, done.
7. **If free credits run out** — Standard plan at $35/mo gives 28,000 credits with commercial rights
